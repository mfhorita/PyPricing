## Pricing:
#### <h3>Pacote de precificação de instrumentos financeiros.</h3>
Módulos:<p>
01.) FinMath	=> Módulo para conversão de taxas e regime de capitalização<p>
02.) Curves		=> Módulo para construção de curvas de juros<p>
03.) Equities	=> Módulo para gestão de carteira de ações, units, ETFs, FIIs, BDRs<p>
04.) Forward	=> Módulo para cálculo de operações a termo, por exemplo: NDFs<p>
05.) Futures	=> Módulo para cálculo de operações futuras<p>
06.) Swaps		=> Módulo para cálculo de operações de swaps: IRS, TRS, CSS, CDS<p>
07.) Options	=> Módulo para cálculo de opções plain vanilla<p>
08.) Bonds		=> Módigo para preficificação de títulos de fixed ou float, corporate ou government<p>
09.) Forex		=> Módulo para gestão de operações de foreign exchange (FX)<p>
10.) Cryptos	=> Módulo para gestão de operações em Bitcoin, Ethereum, Tether etc<p>
11.) Models		=> Modelos de cálculo, Black&Scholes, Vasicek, Basket Levy, Hull White etc<p>
12.) Workadays	=> Módulo para feriados do Brasil, Estados Unidos, Luxemburgo e Reino Unido<p>
